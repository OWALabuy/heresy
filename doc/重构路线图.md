# Python 重构路线图与里程碑

## 0. 基线
- 兼容现有数据库与目录结构：`~/.heresy/heresy.db`、`~/.heresy/xray_config.json`
- 明确外部依赖：`xray`、`hysteria`/`hysteria-windows-amd64.exe`

## 1. 里程碑一：最小可用 CLI（MVP）
范围：订阅更新、节点列表/选择、配置生成、启动/停止 Xray、系统代理开关
- 任务
  - Python 项目脚手架（`pyproject.toml`）与依赖：`typer rich requests pydantic sqlite3`
  - 数据访问层：读取/写入既有 SQLite
  - 订阅更新：下载→base64→解析→事务写入
  - 节点列表/选择：持久化 `current_node_id`（配置文件）
  - 配置生成：协议适配 outbounds + 默认 inbounds/routing
  - 进程管理：安全子进程启动/停止，hy2 联动
  - 系统代理：Windows `winreg`、Linux `gsettings`
  - 基础日志与错误处理
- 验收：命令树全部可用，能连通代理并成功访问外网

## 2. 里程碑二：可靠性与可观测性
- 增加单元测试（pytest），覆盖解析与配置生成
- 增加结构化日志与文件日志
- 诊断命令完善（进程状态/配置校验/最近错误）
- 更严格的输入校验与异常分类

## 3. 里程碑三：易用性增强
- 批量更新订阅；节点筛选（协议/关键字/延迟）
- TCP/HTTPS 延迟测试；结果缓存
- 导入/导出单节点链接
- 代理端口与 inbounds 可配置

## 4. 里程碑四：分发与集成
- PyInstaller 打包并发布（Windows、Linux）
- 提供二进制路径自动发现与配置引导
- 简易安装脚本与 README

## 5. 里程碑五（可选）：界面与 API
- TUI（textual）或 GUI（Qt/Flet）
- REST API（FastAPI）+ 前端面板
- 开机自启与托盘集成

## 风险与缓解
- 不同桌面环境代理设置差异：能力检测与降级提示
- 外部二进制缺失：启动前校验并引导下载/配置
- 解析差异：对异常行记录并容错，不阻断整体流程
