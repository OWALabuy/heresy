# 协议解析与出站生成（MVP+）

本文档记录 src/__main__.py 中的节点链接解析逻辑与 Xray 出站配置生成规则。

## 1. 支持的协议
- vless（含 reality 参数与 ws/grpc 传输）
- vmess（标准 base64 JSON，含 alterId/tls/net/host/path/sni）
- trojan（支持 ws/grpc 相关 query；密码复用在 uuid 字段）
- ss（shadowsocks，支持 base64 与明文两种链接格式）
- hy2（仅解析，暂不生成出站；后续联动 Hysteria2）

## 2. 解析规则要点
- 通用：
  - addr/port 缺省端口按 443 处理
  - 片段 #tag 作为 info
  - extra_params 存放无法落入通用列的协议特有字段（JSON 字符串）

- vless：
  - 基础：uuid@addr:port?type=...&security=...
  - 传输：type=ws|grpc，对应 host/path 或 serviceName
  - TLS：security=tls|reality|none
  - REALITY：pbk/sid/spx/fp/sni/flow 收集至 extra_params

- vmess：
  - 链接体为 base64 的 JSON：add/port/id/ps/net/tls/scy/host/path/sni/aid
  - aid/alterId 归一化为 extra_params.aid

- trojan：
  - trojan://password@addr:port?...#tag
  - 传输：type=ws|grpc，host/path/serviceName
  - TLS：默认 tls；sni 进入 extra_params

- ss：
  - 两种：ss://base64(method:password@host:port)#tag 或 ss://method:password@host:port#tag
  - method 写入 encryption，password 写入 uuid

- hy2：
  - 解析 sni/obfs/obfs-password/insecure，后续用于生成 hysteria2 客户端配置

## 3. 出站生成
- 通用：
  - streamSettings.network 来自 type
  - wsSettings/grpcSettings 从 extra_params 注入
  - TLS：
    - security=tls → streamSettings.tlsSettings.serverName = sni
    - security=reality → streamSettings.realitySettings 注入 publicKey/shortId/spiderX/fingerprint/serverName

- vless：
  - vnext[].users[].id = uuid
  - encryption 默认为 none
  - 若存在 flow 则注入 users[0].flow

- vmess：
  - vnext[].users[].id = uuid
  - alterId 来自 extra_params.aid（默认 0）
  - security 默认 auto

- trojan：
  - servers[].password = uuid
  - 可选注入 sni

- shadowsocks：
  - servers[].method = encryption
  - servers[].password = uuid

- hy2：
  - 生成 `~/.heresy/hy2_config.yaml`，监听本地 socks(10810)/http(10811)
  - Xray 出站改为 socks，地址 127.0.0.1:10810，实现“用 Xray 分流，转发到 Hy2”
  - `proxy start` 先启动 hysteria2，再启动 Xray；`proxy stop` 同时停止二者

## 4. 兼容性与容错
- base64 解码容错性：追加 == 并 errors="ignore"
- 解析失败的单行将跳过并计入失败数，不影响整体事务
- 未来将为各协议增加更严格校验与单元测试
